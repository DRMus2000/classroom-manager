# 使用教程

这份说明给上课的老师。学生不用账号。浏览器打开学校部署好的地址，用教师账号登录。

页面能完成日常课堂操作。学期和班级在左侧「管理」里建立。名单在课堂工具栏的「名单」里添加、修改、离班、恢复和导入。

## 1. 登录

登录页标题是「电脑室积分」，表单是「教师登录」。填写用户名和密码，点「登录」。

页面上写着：学生无需登录。要投到大屏，请用已经登录的电脑进入「展示」，没有免登录链接。

如果浏览器提示证书不受信任，说明服务器还在用自签证书。录入真实学生之前，换成学校的可信证书。见 `docs/DEPLOY.md`。

左下角头像菜单里有三项：

- **修改密码**：至少 12 位。保存后其他设备要重新登录，这台电脑保持登录。手机上没有左侧菜单，到「管理」页下方的「修改密码」。
- **退出其他设备**：这台电脑保持登录，其他电脑上的会话失效。
- **退出登录**：只退出这一台。

忘记当前密码时，在服务器上执行 `reset-password`（见下文「还没有页面入口的事」）。

## 2. 第一次登录会看到转圈

迁移和创建教师账号之后，库里还没有学期，也没有班级。这时：

- 左上角副标题是「尚无当前学期」。
- 顶栏班级位置写着「选择班级」，下拉框是空的。
- 顶栏橙色标签是「未设置当前学期」。
- 「课堂」「卫生」「榜单」「点名」中间写着「还没有可以上课的班级」，按钮是「去建立」。
- 左侧和手机底部都有「管理」。手机上学期标签会藏起来，从底部「管理」进去。
- 「全屏展示」能打开，但是空白，上面有「座位 / 榜单 / 点名」和关闭按钮。

这不是页面坏了。学期和班级在「管理」里建好之后，顶栏会出现班级名和人数，座位图才会出来。

## 3. 开班前的准备

教师账号仍在服务器上创建。学期、班级和名单在页面上建立。后面仍用接口的步骤，登录后要留下 Cookie。把 `https://你的地址` 换成实际地址。自签证书时给 `curl` 加上 `-k`。密码不要写进仓库。

### 3.1 教师账号

生产环境在容器里创建（密码至少 12 位，需要输入两次）：

```bash
docker compose exec api node dist/cli/index.js create-teacher --username teacher
```

本地开发是 `npm run cli -- create-teacher --username teacher`。账号已经存在时，这条命令会拒绝，改密用 `reset-password`。

### 3.2 登录并记下 Cookie

```bash
BASE=https://你的地址
curl -sS -c cookies.txt -H 'content-type: application/json' \
  -d '{"username":"teacher","password":"你的密码"}' \
  "$BASE/api/v1/auth/login"
```

后面的命令都带 `-b cookies.txt`。

### 3.3 建立并启用学期

打开「管理」。页面上方如果是橙色提示「还没有当前学期」，记分还不能用。

在「学期」一栏填写名称，例如「2026 秋季」，点「建立学期」。新建的学期不会自动变成当前学期。再点这一行的「设为当前」。第一次启用时，确认框按钮是「设为当前学期」。

同一时间只能有一个开放学期。点某一行可以看这个学期的记分批次和流水条数。

### 3.4 建立班级

仍在「管理」。在「班级」一栏填写名称，例如「初一1班」，点「建立班级」。顶栏会出现班名和人数。

同名的在用班级不能再建。改名点「改名」，保存前可以取消。归档前会再确认一次：班会退出日常列表，学生和历史还在，本页下方「已归档」里可以「恢复」。

机房在迁移时已经有 54 个座位，编号 1 到 54。不用先画座位。要加减座位或调转某一列，见 3.7。名单在「课堂」工具栏的「名单」里添加或导入。

### 3.5 名单

在「课堂」工具栏点「名单」。

添加一名学生：填写学号、姓名，备注可以空着，选一个空座，点「添加」。班里已经有这个学号时，页面会提示，不会写成两个人。

修改：在这一行点「修改」，改完点「保存」，也可以在输入框里按回车。学号可以改，学生还是同一个人。

离班：点「离班」，选择原因。选「其他」时要写说明。再输入这名学生现在的姓名，点「确认离班」。座位会空出来，积分和卫生记录还在。切到「已离班」可以「恢复」，恢复时要选一个空座。

导入整份名单：切到「导入」。

- 「下载行表模板」。工作表名叫「名单」，从第 2 行填写，列顺序固定：学号、姓名、座位号、备注。座位号填现在显示的编号，必须是已经存在的机位。空行会忽略。
- 或者「下载平面座位表」。工作表名叫「座位表」，每个有人的格子写成 `12号：20240101 张三`。
- 一个文件里不要同时放「名单」和「座位表」。只接受 `.xlsx`，最大 2MB。不要把公式的文本写进学号或姓名。
- 点「选择文件并预览」。看新增、更新、保留和换座的人数。有错误时按钮是「请先修正文件」，这一份不会写入任何人。
- 没有错误时点「确认导入」。文件里没有出现的学生会保留。同学号改了姓名，预览里会标「姓名有变化」。已离班或已匿名的学号不能再次认领。

预览和确认之间如果座次被另一台设备改过，确认会被拒绝，重新预览后再导入。

### 3.6 记分原因和普通标记

没有原因时，座位图底部只有 `+1`、`+2`、`−1`、`−2` 和「自定义」。

打开「管理」，点「维护原因和标记」。

记分原因：

- 填写名称，选择「加分」或「扣分」，再填分值。加分只能是正的，扣分只能是负的。建好之后不能把方向反过来。
- 「所有班级」每个班的记分栏都能用。「只在这个班」只出现在当前班。
- 「本班不用」把它从当前班的记分栏拿下，需要时再「在本班显示」。
- 「修改」里，全校原因默认「只改这个班」。要改每个班，点「改全部班级」。

普通标记不加分，也不是卫生管理员。选一个符号和颜色，点「添加」。下面选一名学生，点「加上」就标到座位上，再点「摘下」去掉。不用的标记点「停用」，已经打过的记号还留在原来的座位上。

做完后回到课堂。顶栏应显示班级名、人数和学期名，例如「教程演示班」「4 人」「2026 秋季」。选中学生后，底部会出现刚加的原因。

### 3.7 机房布局

打开「管理」，点「调整布局」。页面从左到右是面对屏幕的四列，上面是讲台。所有班级共用这一间电脑室。

- 「讲台端加一座」和「后墙端加一座」会先列出将要变化的座位号。点「确认调整」才写入，点「取消」不会改。
- 点一座空座位，再点右边的「删除这座」。有学生的座位会写出占用的班级，按钮是「不能删除」。先把人换走。
- 「调转编号方向」只改变这一列从哪一头开始数。学生还坐在原来的机位上。
- 「调转椅背」不改变座位号。
- 「检查编号」用来看现在的号是否已经符合规则。符合时只有「知道了」。

已经记过的分数仍写着当时的座位号。

## 4. 课堂

左侧或手机底部进入「课堂」。

座位图上方是讲台，下面按列排开。点列首的圈码可以选中这一列有人的座位。工具栏可以在「座位图」和「列表」之间切换，也可以缩放。右侧「名单」用来添加、修改、离班、恢复和导入学生。手机上默认不把整间教室缩进屏幕，可以平移查看；底栏是「课堂 / 卫生 / 榜单 / 点名 / 展示 / 管理」。

未选中学生时，底部提示：单击选择，Ctrl 增减，拖动框选，点列号选整列，Ctrl+A 全班，Esc 取消。

### 4.1 记分

点一名学生，底部出现记分栏，写着「点击即记分」。

- 点 `+1`、`+2`、`−1`、`−2` 会立刻记上一笔。成功时右上角提示姓名和分值，例如「陈一 +1」，并带「撤销」。
- 建过原因模板时，同一栏里有「认真听讲 +1」「未完成任务 −1」这类按钮。方向跟模板走，不能在按钮上改成相反符号。
- 「自定义」可以自己填分值，1 到 1000。不选原因时记为「未选原因」。
- 选中多名学生时，底部会写「提交前确认」。确认框标题是「确认批量记分」，这几个人算同一批次。
- 「全班」一次选中所有在座学生。

当前学期不是开放状态时，记分栏不可用，并提示「当前学期不可写入」。

点「记录」打开「记分记录」。可以撤销整批，也可以撤销其中一条。撤销是再记一笔相反的分数，原来那一条还在。已经撤销过的不能再撤。

### 4.2 换座

点「换座」。草稿只在这台电脑上，点「确认换座」之后才保存。

1. **选择学生**。可以多选，也可以点列号。然后「下一步」。
2. **选择目标**。先点中的那名学生要去的座位，其余人保持相对位置跟着走。目标超出教室时不能继续。
3. **预览确认**。列表里能看到每人从几号到几号。被带着轮换、但你没有点选的人会标「受影响」。确认后提示「换座已保存」。

另一台设备如果刚改过座次，预览会提示过期，点「按最新座次重新预览」。

## 5. 卫生

卫生不改变积分。进入「卫生」。

没有管理员时，页面写「暂无卫生管理员」。点「开始新一轮检查」。本轮开始时如果没有在任的原管理员，名单是空的，这是正常的。

然后：

1. 点「冻结候选」。没有符合条件的原管理员时，候选池是空的。
2. 在「录入新发现的未推椅子学生」里选择学生。
3. 按钮是「直接新任」。候选池为空时，点下去立刻生效，这个人出现在「下一轮新任人员」，进度是 `0/3`，不会再弹出确认框。
4. 以后的轮次如果候选池里有人，按钮变成「抽选替补」。这时会先给出「抽选结果 · 待确认」：左边是将退役的原管理员，右边是新任。可以「关闭预览」或「确认替补」。关闭后结果还在，可以「重新打开预览」。确认之后，新任的人下一轮才开始值日，本轮不计次。

已经有在任管理员时，一轮检查是：

- 勾选实际打扫的人，点「计次」。达到应完成次数的人自动退役。
- 「未推椅子」登记本轮再次没推椅子。
- 「未参加」要再确认一次，应完成次数加 1，本轮不计完成，也不能被抽去替补。
- 铅笔图标是人工纠正。
- 勾完再「冻结候选」，然后才能抽选。
- 「结束本轮」之前如果还有未确认的抽选，要先处理。结束后不能再补本轮的未推椅子记录。

## 6. 榜单和回放

「榜单」里可以看「本班」或「全部班级」，也可以切换学期。旧学期标着「只读」。

同分的人排名相同，下一名会跳过，页面写着「同分并列（1、1、3），较早达到当前分数者在前」。右上角「导出」下载当前这份榜单。

「动态回放」把每个积分批次当成一帧，显示当时的前 10 名。可以选「学期累计」或「区间净增减」，改日期后点播放，或拖动时间轴。倍速有 `0.5×`、`1×`、`2×`、`4×`。区间里没有积分变化时，会写「所选区间内没有积分变化」。

## 7. 点名和倒计时

「点名」页上半部分是随机点名，下半部分是倒计时。

点名：

- 范围选「全班」或「指定学生」。
- 「临时排除」用来去掉缺席的人，只影响这一轮，不影响卫生和积分。
- 看「点名池」人数，点「开始点名」。
- 用加减号决定一次抽几人，点「抽取」。抽中的人显示座位号和姓名，本轮不会再抽到。
- 点名过程中还可以再「临时排除」。
- 「结束本轮」之后才能开新的一轮。

倒计时预设有 30 秒、1 分、3 分、5 分、10 分，也可以自己填分和秒再点「设定」。开始按钮会带上时长，例如「开始 00:30」。进行中可以「暂停」「继续」。到时圆环里显示「时间到」。全屏展示会同步这个倒计时。

## 8. 全屏展示

左侧「全屏展示」或顶栏「展示」进入。画面上是座位号和姓名，不放备注和管理按钮。

三个切换是「座位」「榜单」「点名」。另一台电脑上新抽到人时，展示会切到点名。倒计时进行时，画面上有同一只钟。

「退出展示」回到课堂。浏览器的系统全屏是旁边另一个按钮，和退出展示不是一回事。

顶栏「实时同步」表示其他已登录设备上的修改会自动出现。断网时它变成「离线」，页面顶部出现「网络已断开」：已打开的内容还在，不能再改，恢复后会自己刷新。可以点「重试连接」。

## 9. 换学期

在「管理」里建立新学期，再点「设为当前」。确认框会写明：所有班级一起进入新学期，在班学生积分从 0 开始，座位、标记和还没结束的卫生留下。按钮是「切换并重新计分」。另一台设备如果刚刚切换过，会提示载入最新状态，不会悄悄覆盖。

旧学期标成「只读，可查询」，不能再记分。点学期名称可以看汇总。

## 10. 页面上还做不到的事

这些能力接口已经有了，页面没有入口。对照表在 `docs/API.md` 的「页面是否调用」。

| 要做的事 | 现在怎么做 |
|---|---|
| 改密码 | 已在「管理」页和头像菜单。忘了当前密码时，在服务器执行 `docker compose exec api node dist/cli/index.js reset-password --username teacher` |
| 修改班级名称、归档班级 | 已在「管理」页。接口仍是 `PATCH /api/v1/classes/:id` |
| 增加、修改、离班、恢复学生，以及导入名单 | 已在「课堂」工具栏的「名单」。接口仍是学生与导入那一组路由 |
| 调整机房有多少座位、列的方向 | 已在「管理」的「调整布局」。接口仍是 `GET /api/v1/layout`、`POST /api/v1/layout/preview-change` 和 `/apply-change` |
| 记分原因和普通标记 | 已在「管理」的「维护原因和标记」。座位卡仍会显示已经打上的标记 |
| 看审计、下载数据库备份 | `GET /api/v1/audit`、`GET /api/v1/backup/records`、`GET /api/v1/backup/download/:backup_id`。恢复命令见 `docs/DEPLOY.md`，不能恢复进正在使用的库 |
| 导出花名册、积分明细 | `GET /api/v1/classes/:id/export/roster`、`GET /api/v1/export/points`。榜单导出在页面上 |
| 匿名化一名学生或整个班 | `POST /api/v1/students/:id/anonymize`、`POST /api/v1/classes/:id/anonymize`。姓名和学号清空后不能还原 |

记分时页面不会填写批次备注。接口虽然接受 `note`，记录抽屉里看不到从页面写出的备注。
