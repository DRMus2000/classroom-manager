# 云上验收

2026-09-25 在这台云主机上用 Docker Compose 启动了 Postgres 16、API、备份任务和 Nginx。证书是本机生成的自签证书，数据是合成学生。真实学生上线前换成可信证书。

## 部署中补上的缺口

- 容器入口会修正可写数据卷的属主，再降到 `nodejs`。API 的备份卷是只读的，跳过不能写的目录。
- 生产进程入口是 `dist/src/server.js`。迁移脚本会同时查找源码旁和镜像根目录的 `migrations/`。
- 新建学期写入 `closed`。同一时间只能有一个 `open` 学期，激活时再打开。迁移 `005` 把默认值改成 `closed`。
- 旧学期记账触发 `55006` 时，HTTP 返回 422 `TERM_READONLY`。
- `GET /classes/:id/seats` 返回已经开始计次的在任卫生任期。
- 备份容器不再继承 API 的 HTTP 健康检查。
- 隐藏密码输入按字符切行，管道一次送来的第二行不会丢掉。
