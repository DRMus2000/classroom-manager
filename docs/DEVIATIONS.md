# 设计与当前代码的差异

规范是 `docs/DESIGN.md`、`docs/SCHEMA.md` 和 `docs/API.md`。下表只保留还没对齐的部分。已经按文档改过的行为不再列在这里。

| 主题 | 规范 | 当前代码 |
|---|---|---|
| 卫生落库 | 轮次状态机整条写入 `duty_*` | 判定在 `src/domain/duty.ts`，还没有卫生服务和路由 |
| 回放、点名、倒计时、导出 | `docs/API.md` 对应接口 | 没有服务，`src/server.ts` 不注册这些路径 |
| 运维脚本 | 检查点、备份、匿名账本重试 | 只有 `scripts/migrate.ts` 和 `cli/index.ts` |
| 前端页面 | 座位图、三步换座、卫生、回放、全屏 | `web/src` 仍只有客户端、SSE 和在线状态。契约枚举已与后端对齐 |
| 测试 | 验收表里的导入、并发、备份 | 已有编号、换座、卫生判定的纯函数测试。没有数据库集成测试 |
| 类型检查 | 服务层能通过当前 Drizzle 类型 | `db.execute` 的返回类型与现有调用方式不一致，这是原有问题，本次没有改查询封装 |
| 运行验证 | 迁移在 PostgreSQL 16 上执行 | 本机这次没有启动数据库，编号用例只覆盖纯函数 |

已经对齐的部分：`renumerate()` 按 ①→②→③→④ 蛇形编号；`planSwap()` 按轮换链处理重叠并带上未选中学生；手机锚点按列偏移和槽位偏移展开；记账后的 `last_change_seq` 使用该批次的回放事件序号；当前榜只含在班学生，并列之后按班级名和学号排序；新增、离班、恢复携带 `expected_version`；换座错误码不再使用部分重叠；SSE 事件种类包含 `rollcall_changed`；`src/server.ts` 提供登录、班级、学期、学生、布局、座次、积分和时间线、事件补发。
